# Minh Quan (Alex Ta) CV Page

GitHub Pages-ready personal CV site for Minh Quan.

This package includes:

- A polished bilingual landing page in `index.html`
- Direct PDF downloads for both CV versions
- Preview images rendered from the live 2026 CV PDFs
- Rendered page previews in both English and Vietnamese
- A lightweight language toggle powered by `script.js`
- Static hosting compatibility for GitHub Pages via `.nojekyll`

## Structure

- `index.html` - landing page
- `styles.css` - page styling
- `script.js` - EN/VI copy and language toggle
- `assets/cv/MinhQuan_CV2026_EN.pdf` - English CV
- `assets/cv/MinhQuan_CV2026_VN.pdf` - Vietnamese CV
- `assets/previews/cv-en-cover.png` - English cover preview
- `assets/previews/cv-vn-cover.png` - Vietnamese cover preview
- `assets/previews/site-home-en.png` - English page preview
- `assets/previews/site-home-vi.png` - Vietnamese page preview

## Publish

1. Push this folder to a GitHub repository.
2. Enable GitHub Pages from the repository root.
3. The site works as a static page with no build step.
4. Use `?lang=vi` for a direct Vietnamese entry URL when needed.
