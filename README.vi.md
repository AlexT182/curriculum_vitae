# Trang CV Minh Quân (Alex Ta)

Trang CV cá nhân sẵn sàng đưa lên GitHub Pages cho Minh Quân.

Bộ này gồm:

- Trang giới thiệu song ngữ trong `index.html`
- Link tải trực tiếp cho cả hai bản CV
- Ảnh xem trước được render từ đúng file PDF CV 2026
- Ảnh xem trước của chính landing page ở cả tiếng Anh và tiếng Việt
- Nút chuyển ngôn ngữ EN/VI bằng `script.js`
- Khả năng host tĩnh trên GitHub Pages qua `.nojekyll`

## Cấu trúc

- `index.html` - trang chính
- `styles.css` - giao diện
- `script.js` - nội dung EN/VI và nút chuyển ngôn ngữ
- `assets/cv/MinhQuan_CV2026_EN.pdf` - CV tiếng Anh
- `assets/cv/MinhQuan_CV2026_VN.pdf` - CV tiếng Việt
- `assets/previews/cv-en-cover.png` - ảnh bìa CV tiếng Anh
- `assets/previews/cv-vn-cover.png` - ảnh bìa CV tiếng Việt
- `assets/previews/site-home-en.png` - ảnh preview trang tiếng Anh
- `assets/previews/site-home-vi.png` - ảnh preview trang tiếng Việt

## Cách publish

1. Đẩy thư mục này lên một GitHub repository.
2. Bật GitHub Pages từ thư mục gốc của repo.
3. Trang chạy tĩnh, không cần build.
4. Có thể dùng `?lang=vi` để mở trực tiếp bản tiếng Việt.
